BoyKeep K11 Local Manager

Aplikasi Konfigurasi Wi-Fi & RTSP Standalone (100% Offline Tanpa Cloud)

Setup via Wi-Fi Hotspot Kamera
Petunjuk Penggunaan:
1. Sambungkan HP/Laptop Anda ke Wi-Fi Hotspot kamera: K11-SETUP (tanpa password).
2. Masukkan nama Wi-Fi rumah dan Password di bawah.
3. Klik Kirim ke Kamera. Kamera otomatis konek ke Wi-Fi rumah Anda!
Generator File MicroSD (wifi.conf)
Metode Paling Praktis & Bebas Ribet:
Isi form di bawah, klik Unduh File wifi.conf, lalu simpan file tersebut ke kartu MicroSD (FAT32). Masukkan ke slot MicroSD kamera lalu nyalakan kamera!
Generator QR-Code Kamera
Masukkan Wi-Fi Anda, klik Generate QR, lalu arahkan layar HP Anda ke depan lensa kamera sejauh 15-20 cm sampai kamera berbunyi 'beep'.

Arahkan QR Code ini ke lensa kamera K11

Live RTSP Streaming
Gunakan URL RTSP ini di aplikasi VLC Player, Home Assistant, TinyCam, atau OBS:
rtsp://192.168.1.150:554/live
rtsp://192.168.1.150:554/sub
telnet 192.168.1.150 23
